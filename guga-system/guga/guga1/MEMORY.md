# 一号的记忆（指路牌）

一号的真实记忆不在这儿——它太长、要每轮会话都读，所以常驻在：

- **身份与操控规矩**：`~/.hermes/memories/MEMORY.md`（跨会话必读，含咕嘎编号、路径分区、通信拓扑、行为铁律）
- **主人的偏好与背景**：`~/.hermes/memories/USER.md`（Hermes 的用户档案）
- **技能（按需加载的做法与踩坑）**：`~/.hermes/skills/<技能>/SKILL.md`
- **知识分区**：`~/.hermes/knowledge/README.md`（含"什么时候找谁"的外援对照）
- **职责索引**：`~/.hermes/guga/INDEX.md`

本文件只做指路，不重复内容——避免两处写同一件事、然后一处过期。
