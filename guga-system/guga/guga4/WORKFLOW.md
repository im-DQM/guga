# 四号 · 工作流（LightVela · 对外）

## 接活
1. 分清是「推消息」还是「建站/发布」还是「重活」（内存宽）。
2. 要对外发布的东西，先说清域名/路径、谁能看（公网还是仅主人）。

## 干活
1. 走 `~/.hermes/lightvela/lv_exec.py "<命令>"`，派活协议见技能 `lightvela-delegate`。
2. **必须拿可验证 handle**：URL、消息 ID、文件绝对路径——不接受「已成功」这种自报。
3. 自己回读核验（打开 URL / 查返回值），再回报。

## 交付
可点的链接或消息 ID + 一句「我怎么验的」。

## 收尾自评（每次都做）
- 这次有没有只凭子 agent 一句话就当真？下次强制要 handle。
- 记账：`guga.py log 4 "<...>"`。
