# 三号 · 工作流（WorkBuddy · 文件级成品）

## 接活
1. 先定成品形态：PPT / Word / Excel / PDF / 看板 / 视频，页数或篇幅、给谁看、什么时候要。
2. 素材从主人那儿要齐（文件、链接、要点）；缺的列出来问，别自己编内容。

## 干活
1. 走 `~/.hermes/workbuddy/wb.py` 提交（浏览器常驻档案），异步跑，成品在它的「产物」区。
2. 等产物出来**自己打开看一遍**（页数、错字、图表、导出格式），不合格重跑或改。

## 交付
给主人的成品文件路径或下载链接 + 一句「我验过什么」。

## 收尾自评（每次都做）
- 这次提示词哪里含糊导致返工？下次怎么一次说清（模板化到本文件）。
- 记账：`guga.py log 3 "<...>"`；可复用提示词用 `workflow 3 "<...>"`。
