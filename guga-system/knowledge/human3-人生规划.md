## 0. 一句话结论

他不缺努力、不缺思考、不缺纪律；缺的是「把东西交到外部世界并被评价」这条通道。通道关闭的代价正由身体（深夜刷直播）和事业（三个月不投简历）两边同时支付。

## 1. 四象限定位

MIND —— 2.3（个体·发现期）
+ 自建六子理论体系并写成定稿长文；能与知己聊到同一层；情绪调节良好（三月稳定，仅数天波动）；能命名自己的机制。
− 误诊瓶颈（1% 转化率归因给"口语"，实为漏斗前端）；框架跑在经验前面（他自己的子理论六「认知错位」就是在描述这个）；把思考工具化（真猪假猪里的"用想"）。
到 3.0 的标志：能把框架变成改变他人的东西，并让「打工」与「一人事业」在两个层次上并存而不是互斥。

BODY —— 1.4（从众·不谐期：认知已到 2.0、行为停在 1.0）
+ 饮食方案已量化成文（认知完全到位）；每日药按时吃（连续 7 天真执行）；**午睡 30 分钟达标**；**有健身基础**（薄肌理论就是从那儿来的），不是零起点。
− 健身习惯近期中断（当前 0 次/周）；日照 0；久坐；00:30 睡 / 08:30 起（总量 8h 够，节律偏晚）；晚上用高刺激娱乐补的是刺激，不是觉。
这是唯一「投入为零」的象限，也是他自己理论里性价比最高的一条。

SPIRIT —— 2.2（个体·不谐向不确定过渡）
+ 女朋友关系稳定（3.5h/天）；有一位同层的室友知己（2–3 天一顿饭）——罕见的同时到达体验；好友知情。
− 女朋友不知道他的求职状态与挫折（关系停在陪伴/玩，未进入共同面对）；理想的一天里没有她；意义感目前靠内部框架 + 一位知己，缺「被更大群体校验」的通道。
+ 有 3.0 的种子：恋爱理论（按对方的收获计价）、同时到达理论 —— 认知已越级，行为未跟进。

VOCATION —— 2.1（个体·不谐期）
+ 每天 7h 硬投入、执行力真实；能独立造系统（hub / 多 agent / 隧道 / 登录门卫）；不认「必须打工」的模板，想自己造路。
− 收入为零；简历 300 份 → 3 面 → 0 通过（转化率 1%）；三个月零投递，停在"准备阶段"；把刷题当成对付面试的万能钥匙。
打工在他的定义里是资金引擎（"挣钱的工作换未来的选择权"），不是身份 —— 这是 2.0 的成熟处，但要小心：把手段当成唯一的路，自由度反而最小。

## 2. Metatype 与瓶颈

类型：接近「教授」（Mind + Spirit 强，Vocation 有技能无变现，Body 最弱）—— 理解深、意义感强；风险是身体脆弱 + 变现失败 + 物质基础不稳。Koe 给的处方：加 Body 续命、加 Vocation 落地。

第一瓶颈 = BODY。理由：①唯一零投入的象限（健身中断、日照为 0）；②他要的"干完主线还留富余精力"以精力为前置；③晚间高刺激补的是刺激不是觉——睡眠总量够，缺的是运动/日照/偏晚节律带来的恢复质量；④他自己的理论也说睡眠与运动是正向循环的基础。
第二瓶颈 = VOCATION 的输出与变现环节（不是技能），与 MIND 的"用想"共用一个病根。

四个陷阱里他踩了两个半：优化陷阱（懂 > 做）、成功陷阱的前身（白天高负荷 → 晚上身体与精神被掏空）、轻度精神绕行（用理论解释处境，代替行动）。

限制性习惯 · 身份认同 · 环境

身份：①"我是技术硬实力型、不善言辞" —— 把能力缺口当成个人特质；②"我是 28 届，岗位少，吃了届别的亏" —— 结构性归因成了三个月不动的护身符（实际上他的主战场是 2027 年 2–6 月的暑期实习窗口，10–12 月本来就是 27 届秋招吃掉的淡季）；③"我技术不够硬"与"我写了一整套思想体系"并存 —— 认知极高、市场估值极低的撕裂自我。

## 4. 要重排的一件事：主线任务

他理想的一天只要一条主线（3–4h）、且要留富余精力。当前实际是每天 5–7h 面试冲刺，把预算全烧在一个不是他真正想要的身份上。

重排（不等价替换，而是重新分配预算）：
- 实习准备 5h → 3.5h（项目 60min + 算法 90min + 八股 60min），释放约 1.5h。
- 释放出的时间：身体 40min（健身 / 日照散步）+ 输出 40min（60 秒口述 / 每周一条公开内容）。
- 刷题标准改口径：不求题量，求「每道做过的题都能 60 秒讲清：思路、复杂度、边界」。这一条同时喂 Vocation（面试）和 Mind（口述通路）。

### 4.1 为什么不等项目完工再投（主人原方案 vs 修订）

主人原计划：项目 11 月做完 → 再写进简历 → 再投。
问题：①12 月–1 月是考试假与年末，日常实习岗位比 10–11 月更少；②拿不到反馈的简历优化等于在黑箱里猜——300:3 的教训不是"我不够好"，而是"渠道与信号没跑通"；③项目的"完成"没有明确终点，它天然是拖延的完美外衣（他自己清单里最贵的一条回避）。
修订（并行，不牺牲项目质量）：
- 项目完工前（现在～11 月）：①简历先把**已完成模块 + 技术栈 + 遇到的难点**写进去，未完成部分留一行"进行中"；②主攻渠道——找 3–5 条内推（学长、老师、牛客、脉脉），渠道不依赖项目完工；③小批量试投 5–10 家，目的不是上岸，是拿真实反馈改简历。
- 项目完工后（11 月）：简历换上完整版，批量投 40 家以上。此时手上已有反馈，转化率才可能从 1% 提到 5%+。

## 4.2 动态排计划的两条硬规矩（2026-10-16 主人定）

- **周六整休**：周六不排任何锚点任务（项目 / 算法 / 八股 / 口述 / 健身都不排）；今天没做完的事也不顺手挪到周六；周六只有早晨那一场复盘。
- **健身不连着排**：任意相邻两天不能都排健身（健身日之间至少隔一天）；要把漏掉的那次补上，就顺延到下一个「不与前一天相邻」的日子，优先周二 / 周四 / 周日，**不排周六**。

### 5.1 「60 秒口述」到底怎么录（主人问）

是什么：用手机录一段最长 60 秒的语音（或自拍视频），把当天做过的一道题讲清楚。**不需要发布，也不需要给任何人看**——第一阶段完全私人。
讲三句就够：①这题要什么（一句话复述）②我的思路、为什么这么做 ③复杂度和边界情况。
三条纪律：不回听、不重录、不看稿，好坏一律不评判——它唯一的目的是把"我知道"变成"我能当场说出来"，并在清单上变成一个能打勾的微任务。
为什么有效：他能连续七天吃药，说明对"有边界、能打勾"的任务执行力极强；口语练习之所以失败，是因为它无边无界、没有勾可打。所以把它挂到已有的刷题习惯后面，作为刷题的最后一步。
进阶（2–3 周后再加，一次只加一步）：对着手机镜头讲（练"看着人讲"）；再往后把一道题讲给室友听。
公开化是 90 天的事：每周 1 条公开内容，那才是 IP 的起点。
