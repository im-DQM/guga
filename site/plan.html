唯一预先排定的结构就是这一条：周一至周五正常，周六整天休息（只在早晨做复盘与下周计划），周日照常干活。复盘内容：本周锚点完成天数、投递与面试数、转化率、下周三个重点、健身排哪三天、哪个成就升了段；末尾另起一节问你两三个问题对齐下周（哪天不方便健身、有没有必须完成的事、这周有什么想让我记住的）。
动态排计划时守两条硬规矩：周六整休——不排任何锚点任务、没做完的事也不往周六挪；健身不连着排——健身日之间至少隔一天，漏掉的那次往后顺延到不相邻的日子，不补到周六。

成就 · 徽章解锁时待办面板会弹一下

四象限定位

心智MIND

2.3 · 发现期
1.0 从众2.0 个体3.0 整合
  • 自建六子理论体系并写成定稿长文，能与知己聊到同一层
  • 情绪调节良好：三个月只有几天波动，不是持续低气压
  • 误诊瓶颈：把 1% 的转化率归因给「口语」，实为漏斗前端
  • 框架跑在经验前面（你自己的子理论六写的就是这个病）
升到 3.0 的标志：框架能改变别人，且「打工」与「一人事业」在两个层次上并存而不互斥。

身体BODY

1.4 · 不谐期
1.0 从众2.0 个体3.0 整合
  • 饮食方案已量化成文，药连续七天不断，午睡 30 分钟达标
  • 有健身基础（薄肌理论就是从那儿来的），不是零起点
  • 健身中断（当前 0 次/周）、日照 0、久坐
  • 00:30 入睡、08:30 起：睡够了，节律偏晚，晚上补的是刺激不是觉
唯一「投入为零」的象限，却是你自己理论里性价比最高的一条。

精神SPIRIT

2.2 · 过渡中
1.0 从众2.0 个体3.0 整合
  • 女朋友关系稳定（3.5h/天）；有一位同层的室友知己，两三天一顿饭
  • 已有 3.0 的种子：恋爱理论（按对方的收获计价）、同时到达理论
  • 女朋友不知道你在求职、也不知道字节那场——关系停在陪伴层
  • 意义感只靠内部框架 + 一位知己，缺「被更大群体校验」的通道
认知已越级（能写出整合层的理论），行为还没跟上——这是这一象限唯一要补的。

事业VOCATION

2.1 · 不谐期
1.0 从众2.0 个体3.0 整合
  • 每天 7h 硬投入、执行力真实；能独立造系统（多智能体 / 隧道 / 门卫）
  • 不认「必须打工」的模板：打工是资金引擎，不是身份
  • 收入为零；300 份简历 → 3 面 → 0 通过（转化率 1%）
  • 三个月零投递，停在「准备阶段」——「等 11 月完工」是最贵的拖延
判定口径按「自由度」算，不按职位算。把手段当成唯一的路，自由度反而最小。
相位 .1 不谐（旧办法失效）→ .2 不确定（身份溶解、成长最快）→ .3 发现（新身份稳定）

类型与瓶颈

Metatype
教授型（心智 + 精神 强，事业有技能无变现，身体最弱）
理解深、意义感强；风险是身体脆弱 + 变现失败 + 物质基础不稳。处方：加身体续命、加事业落地。
第一瓶颈
身体
你要的是「干完主线还留富余精力」，而精力是前置条件；睡眠总量够，缺的是运动、日照与正常节律。
第二瓶颈
事业的输出与变现（不是技能）
与心智的「用想」共用一个病根：懂 > 做。
行为 vs 目标
目标拿实习 → 三个月零投递；想做 IP → 公开发布 0 次；想要富余精力的一天 → 每天透支再补偿。
回避清单
投简历、见真实的人（最贵）＞ 公开输出 ＞ 健身与早睡。
共同点：都需要被外部看见。你能连续七天吃药，却做不了这三件——因为它们没有勾可打。
限制性身份
「技术型、不善言辞」「28 届岗位少吃了亏」「技术不够硬」——最后一条和上一句「我写了一整套思想体系」并存。

路线图

30 天→ 11 月中旬
断链 · 打开漏斗 + 身体还债
  • 事业 项目约一周内完工（10/23 前后）；随后简历 v2 + 批量投 40 家以上
  • 事业 找 3–5 条内推（学长 / 老师 / 牛客 / 脉脉）——把转化率从 1% 拉起来的头号手段
  • 身体 恢复健身，每周 3 次（用以前那套老计划，不要重新设计）
  • 身体 每天日照散步 15 分钟；23:45 前上床；起床向 08:00 靠
  • 心智 每天 录一条 60 秒口述
  • 精神 每周一次和女朋友聊「各自的规划」
验收：11 月中前拿到 ≥1 个面试机会；锚点各项 ≥20/30 天。
90 天→ 2027 年 1 月中
登岸 · 日常实习上岸（硬约束 1/15）
  • 事业 日常实习到手，或稳定进入面试循环；简历每 2 周迭代一次
  • 心智 60 秒录音晋级为 每周 1 条公开内容（IP 起点，你已选择暂缓）
  • 身体 健身稳定每周 3 次；睡眠稳定 23:30–07:30 区间
  • 心智 把牛肉粉理论公开一次，收第一次外部校验
  • 备选 若日常实习未成：12–2 月改补「可展示的产出」，把 3–4 月暑期实习当主战场
28 届暑期实习窗口是 2027 年 2–6 月（4–6 月高峰）。现在这几个月本来就被 27 届秋招吃掉，别读成「我的届别吃亏」。
180 天→ 2027 年 4 月中
夺旗 · 28 届暑期实习主战场
  • 事业 暑期实习至少 1 个 offer 或稳定进入流程；手上要有实习履历 + 公开作品 + 内推网络
  • 影响力 公开内容累计 25 条以上，至少一条小回响
  • 精神 关系里出现「共同面对」的部分
  • 身体 体能与体成分有一个可指的变化
  • 备选 若暑期不理想，2027 年 8–10 月秋招是 28 届真正的决战
